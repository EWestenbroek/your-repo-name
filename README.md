# Braindump

A centralized dump of pet project ideas — things I might build someday, or never. No pressure, no roadmap, just a place to park ideas before they evaporate.

## How this works

Each idea gets its own file in [`ideas/`](ideas/), based on [`ideas/TEMPLATE.md`](ideas/TEMPLATE.md). Keep entries short — this is a scratchpad, not a spec.

Add new ideas to the index below when you create them.

## Workflow

Every idea lives on its own branch: `idea/<slug>`, e.g. `idea/local-first-notes`. Add the idea's markdown file (and any code, if it goes beyond notes) on that branch, and keep working there for as long as the idea is alive. Only merge to `main` if/when an idea is actually done or you want it permanently promoted out of "maybe someday" status.

## Status legend

- `idea` — just written down, nothing explored yet
- `exploring` — poking at feasibility, no commitment
- `in progress` — actively being built
- `shelved` — parked, might revisit
- `done` — built it (link to the resulting repo/project if separate)
